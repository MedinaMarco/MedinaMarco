## 📌 Proyecto destacado

### 🧠 NeuroLab — Tutorial Interactivo de Redes Neuronales

> App web educativa que explica cómo funciona y aprende una red neuronal multicapa,
> implementada **desde cero con NumPy** — sin TensorFlow ni scikit-learn.

**Qué incluye:**
- MLP completo: forward pass, backpropagation y gradient descent con álgebra matricial pura
- Visualización de la frontera de decisión animada epoch a epoch
- 6 actos narrativos para explicar los conceptos sin conocimientos previos
- Sección matemática con derivación completa de backpropagation

**Stack:** Python · NumPy · Streamlit · Plotly · Pandas

[![Ver repositorio](https://img.shields.io/badge/Ver_repositorio-171515?style=for-the-badge&logo=github&logoColor=white)](https://github.com/MedinaMarco/neurolab)
